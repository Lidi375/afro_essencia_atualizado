Sobre o projeto

Sistema de agendamento completo

Esta página é a vitrine estática do projeto. O sistema completo — agendamento online, painéis de cliente, profissional e administrador, anamnese capilar, pagamentos via Mercado Pago, comissões e relatórios financeiros — está no código-fonte do repositório.

  • PHP 8 (MVC + DAO + Services)
  • MySQL / MariaDB
  • PHPMailer
  • Mercado Pago
  • HTML · CSS · JavaScript
  • Testes com Pytest

O backend PHP precisa de um servidor com PHP e MySQL; o GitHub Pages hospeda somente esta vitrine.
